# Sounds Directory

Place your audio file here for the dramatic reminder popup!

Supported filenames (put your file here):
1. `public/reminder.mp3` or `public/sounds/reminder.mp3`
2. `public/reminder.mp4` or `public/sounds/reminder.mp4`
3. `public/reminder.wav` or `public/sounds/reminder.wav`

If no custom audio file is placed, a built-in dramatic gunshot & alert sound synthesizer (Web Audio API) will play automatically!
